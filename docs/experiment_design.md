# Prespecified experiments

This grid was specified before seeing test results. The winning configuration within each model/area is the one with minimum December 9-15 validation RMSE. Ties retain the earlier, simpler candidate. The test week never drives another parameter change.

- **AR:** Start with the most recent six lags (one hour), then twelve (two hours), then twelve plus daily and weekly lags. This separates the value of additional recent history from explicit periodic history. Seasonal candidates have fewer usable training rows because they require one week of context.
- **Holt-Winters:** Compare a persistent additive trend with a damped trend under the same 144-step additive seasonality. Damping tests whether reducing trend extrapolation improves validation performance. Estimated states and smoothing coefficients use the training period only. This is the statistical model most directly tied to a daily template.
- **LSTM:** Cross two-hour/day-long inputs with 16/32 hidden units. The grid separates context length from capacity, without extra layers or architecture variants. Each experiment uses the same optimizer and seed. Early stopping selects an epoch within each candidate, then validation RMSE chooses the configuration. The final fit resets its weights and scaler and uses the selected number of epochs.

`experiments.csv` records every candidate and its measured validation errors and training time; `epochs.csv` records every LSTM epoch and checkpoint-selection evidence. `fitted_parameters.json` records final AR coefficients, Holt-Winters smoothing and convergence, and LSTM normalization/parameter counts. The report explains the observed differences. This is parameter optimization by a small predefined grid, explicitly allowed by activity.tx; it does not claim an open-ended manual search or a global optimum.

The initial Holt-Winters run exhausted the library's default optimization budget. Its preliminary results were replaced after raising the L-BFGS-B limits to 2,000 iterations and 100,000 function evaluations. All six validation fits and three final fits must now converge; otherwise execution raises an error. This change was triggered by numerical convergence diagnostics, not by test-set performance. `python src/experiment.py --only Holt-Winters` refreshes that model in completed outputs while preserving AR and LSTM experiments. Final tables contain only the converged runs.
